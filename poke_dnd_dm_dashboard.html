🎲 How it works

1
Create one campaign for the whole game
Click Create a New Campaign once. Every session uses the same campaign, so characters, maps and models carry over.
2
Send the ID to your players
Click Copy invite at the top of your dashboard and paste it in the group chat. Each player opens their sheet, taps No campaign, pastes the ID with their name and taps Join & Sync. Their character appears here live.
3
Build the map and play
🗺 Board opens the live 3D board: build scenes by hand or describe them in words, then show them to the players. ⚔ Encounter runs initiative and foes, and 🎬 Scene sets weather and sends messages to every sheet.
4
Next time
This dashboard remembers your campaign and connects by itself. Everything is saved in the group's database, so nothing needs setting up.
Old Google Script relay setup (not needed: the group uses Firebase)
1
Open Google Apps Script
Go to script.google.com and sign in with any Google account. Click New project.
2
Paste the backend code
Delete everything in the editor and paste this code:
const PROPS = PropertiesService.getScriptProperties(); function doGet(e) { const id = e.parameter.id; if (!id) return respond({error:'Missing id'}); const raw = PROPS.getProperty('campaign_'+id); return respond(raw ? JSON.parse(raw) : {}); } function doPost(e) { try { const b = JSON.parse(e.postData.contents); if (!b.id) { const id = Utilities.getUuid().replace(/-/g,'').slice(0,16); PROPS.setProperty('campaign_'+id, JSON.stringify({})); return respond({id}); } const raw = PROPS.getProperty('campaign_'+b.id); const c = raw ? JSON.parse(raw) : {}; c[b.playerKey] = {...b.data, _updated: Date.now()}; PROPS.setProperty('campaign_'+b.id, JSON.stringify(c)); return respond({ok:true}); } catch(err) { return respond({error:err.message}); } } function doOptions(e) { return respond({}); } function respond(data) { const o = ContentService.createTextOutput(JSON.stringify(data)); o.setMimeType(ContentService.MimeType.JSON); return o; }
3
Deploy as a Web App
Click Deploy → New deployment. Set type to Web app. Under "Who has access" choose Anyone. Click Deploy. Copy the URL that appears — it looks like https://script.google.com/macros/s/ABC…/exec
⚠ You must set access to "Anyone" (not "Anyone with Google Account") for the character sheets to sync without requiring login.
4
Paste the URL here + in every player sheet
Paste the relay URL into the box on the left and into every player's sheet (the "No Campaign" button → relay URL field). Then one player creates a campaign, gets an ID, and everyone else joins with that ID.
5
That's it — permanent from here
The relay URL and campaign ID never change. Everyone just opens their HTML file and it syncs automatically. No server, no subscription, no expiry.
